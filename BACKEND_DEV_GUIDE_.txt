## 📁 项目结构

```
prts-backend/
├── pom. xml                                 # Maven 配置
└── src/main/
    ├── java/com/hourai/prts/
    │   ├── PrtsApplication.java           # 启动类
    │   ├── controller/                    # 控制器层
    │   │   ├── UserController.java
    │   │   ├── QuestionController.java
    │   │   ├── AnswerController.java
    │   │   └── ExamController.java
    │   ├── service/                       # 业务层
    │   │   ├── IUserService.java
    │   │   ├── IQuestionService.java
    │   │   ├── IAnswerService.java
    │   │   ├── IExamService.java
    │   │   └── impl/                      # 实现类
    │   ├── mapper/                        # 数据访问层
    │   │   ├── UserMapper.java
    │   │   ├── QuestionMapper.java
    │   │   ├── UserAnswerMapper.java
    │   │   ├── ExamRecordMapper.java
    │   │   └── ExamDetailMapper.java
    │   ├── entity/                        # 实体类
    │   │   ├── User.java
    │   │   ├── Question.java
    │   │   ├── UserAnswer.java
    │   │   ├── ExamRecord. java
    │   │   └── ExamDetail.java
    │   ├── dto/                           # 请求对象
    │   │   ├── LoginDTO.java
    │   │   └── ExamSubmitDTO.java
    │   ├── vo/                            # 响应对象
    │   │   ├── UserVO.java
    │   │   └── ExamResultVO.java
    │   ├── common/                        # 公共类
    │   │   ├── Result.java               # 统一响应
    │   │   ├── PageResult.java           # 分页响应
    │   │   └── ErrorCode.java            # 错误码
    │   ├── config/                        # 配置类
    │   │   ├── MyBatisPlusConfig.java
    │   │   ├── CorsConfig.java
    │   │   └── Knife4jConfig.java
    │   ├── exception/                     # 异常处理
    │   │   ├── GlobalExceptionHandler.java
    │   │   └── BusinessException.java
    │   └── utils/                         # 工具类
    └── resources/
        ├── application.yml                # 配置文件
        ├── application-dev.yml            # 开发环境
        └── db/
            ├── schema.sql                 # 建表脚本
            └── data.sql                   # 初始数据
```

## ⚙️ 配置说明

### 1. pom.xml 关键依赖

```xml
<dependencies>
    <!-- Spring Boot Web -->
    <dependency>
        <groupId>org.springframework. boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    
    <!-- MyBatis-Plus -->
    <dependency>
        <groupId>com.baomidou</groupId>
        <artifactId>mybatis-plus-boot-starter</artifactId>
        <version>3.5.5</version>
    </dependency>
    
    <!-- MySQL Driver -->
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
    </dependency>
    
    <!-- Knife4j -->
    <dependency>
        <groupId>com. github.xiaoymin</groupId>
        <artifactId>knife4j-openapi3-jakarta-spring-boot-starter</artifactId>
        <version>4.3.0</version>
    </dependency>
    
    <!-- Hutool -->
    <dependency>
        <groupId>cn.hutool</groupId>
        <artifactId>hutool-all</artifactId>
        <version>5.8.25</version>
    </dependency>
    
    <!-- Lombok -->
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
    </dependency>
    
    <!-- Validation -->
    <dependency>
        <groupId>org.springframework. boot</groupId>
        <artifactId>spring-boot-starter-validation</artifactId>
    </dependency>
</dependencies>
```

### 2. application.yml 配置

```yaml
server:
  port: 8888

spring:
  application:
    name: prts-backend
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/prts_db?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: GMT+8

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging. stdout.StdOutImpl
    map-underscore-to-camel-case: true
```

### 6. 数据库表设计要点

- id：主键，自增

- question_id：题目 ID（索引）
- selected_answer：用户选择
- is_correct：是否正确
- created_at：答题时间

**exam_record 表**：
- id：主键，自增
- user_id：用户 ID（索引）
- total_questions：题目总数
- correct_count：正确题数
- score：得分
- created_at：考试时间

**exam_detail 表**：
- id：主键，自增
- exam_id：考试 ID（索引）
- question_id：题目 ID
- selected_answer：用户选择
- is_correct：是否正确

## ❓ 常见问题

### Q1: 数据库连接失败？
**A**: 
1. 检查 MySQL 是否启动
2. 检查用户名密码
3. 检查数据库是否存在
4. 检查 URL 是否正确

### Q2: MyBatis-Plus 查询返回 null？
**A**:
1. 检查表名是否正确（@TableName）
2. 检查字段映射（下划线转驼峰）
3. 查看 SQL 日志

### Q3: 跨域问题？
**A**:
1. 确认 CorsConfig 配置正确
2. 确认前端地址在允许列表
3. 检查浏览器控制台错误信息

### Q4: 接口返回 500 错误？
**A**:
1. 查看后端控制台日志
2. 检查数据库连接
3. 检查参数是否正确
4.  使用 Postman 测试

### Q5: Knife4j 访问 404？
**A**:
1. 确认配置正确
2. 访问：http://localhost:8888/doc.html
3. 检查 Spring Boot 版本兼容性

### Q6: JSON 字段存储和查询？
**A**:
1. 存储：使用 JSON. toJSONString() 转为字符串
2. 查询：使用 JSON.parseArray() 解析
3. 考虑使用 TypeHandler 自动转换

### Q7: 分页查询如何实现？
**A**:
1. 使用 MyBatis-Plus 的 Page 对象
2. 在 Service 中创建 Page<Entity>
3. 调用 mapper.selectPage(page, wrapper)

### Q8: 如何优化慢查询？
**A**:
1. 创建合适的索引
2. 避免 SELECT *
3. 使用 EXPLAIN 分析查询
4. 考虑缓存
